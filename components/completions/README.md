# Completions component
# Provides shell completion for meowctl and meow-theme commands

This component installs shell completions for:
- meowctl (preset management, component management, theme management)
- meow-theme (theme switching and configuration)

Supported shells:
- zsh (with advanced completion features)
- bash (with basic completion)

The completions provide:
- Command completion
- Preset name completion from your presets directory
- Component name completion from your components directory
- Theme preset and variant completion from themes.yaml
- Option and flag completion
